# DraftCluster

DraftCluster is a high-performance, cloud-based platform that powers real-time collaborative workflows through auto-scaling and load balancing engine capabilities.

The key benefits of using DraftCluster include:

- DraftCluster is a high-performance, cloud-based
- platform that powers real-time collaborative
- workflows through auto-scaling and load

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/DraftCluster.git`
2. `cd DraftCluster`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
